Лабораторная работа №4

Реализация клиентской части средствами Vue.js

Практическая работа 4.1

(Базовые конструкции JavaScript)

В рамках подготовки к лабораторной работе были изучены базовые конструкции JavaScript: - переменные (let, const) - функции - стрелочные функции - массивы и методы массивов - работа с объектами - async/await - обработка ошибок через try/catch

Практическая работа носила ознакомительный характер и отдельно не сдавалась.

Практическая работа 4.2

(Работа с Vue.js)

В ходе выполнения практической работы были изучены:

  • создание проекта на Vue 3 через Vite
  • структура проекта
  • компоненты и views
  • реактивность (ref, reactive)
  • lifecycle hooks (onMounted)
  • работа с axios
  • маршрутизация через Vue Router
  • навигационные guard’ы
  • подключение UI-библиотеки Vuetify

В результате был создан frontend-проект с разделением на: - src/api - src/router - src/views - src/plugins

Практическая работа 4.3

(Настройка CORS)

Для обеспечения взаимодействия frontend и backend был настроен CORS.

Использована библиотека: - django-cors-headers

В settings.py добавлено:

  • corsheaders.middleware.CorsMiddleware
  • CORS_ALLOWED_ORIGINS:
  • http://127.0.0.1:5173
  • http://localhost:5173

Это позволило frontend-приложению на Vue обращаться к API Django.

Лабораторная работа №4

Реализация клиентской части приложения

Предметная область

Менеджер задач.

Используемые технологии

Backend: - Django - Django REST Framework - Djoser - PostgreSQL - Token Authentication

Frontend: - Vue 3 - Vite - Vue Router - Axios - Vuetify

Реализованные интерфейсы

Авторизация

  • Регистрация пользователя
    POST /auth/users/

  • Вход пользователя
    POST /auth/token/login/

  • Получение текущего пользователя
    GET /auth/users/me/

  • Изменение данных пользователя
    PATCH /auth/users/me/

  • Выход пользователя
    Удаление токена на фронтенде

Токен передаётся в заголовке: Authorization: Token

Категории

  • Создание категории
  • Получение списка категорий
  • Удаление категории

Эндпоинты: - GET /api/categories/ - POST /api/categories/ - DELETE /api/categories/{id}/

Задачи

  • Создание задачи
  • Получение списка задач
  • Изменение статуса задачи (PATCH)
  • Удаление задачи

Эндпоинты: - GET /api/tasks/ - POST /api/tasks/ - PATCH /api/tasks/{id}/ - DELETE /api/tasks/{id}/

Теги

  • Создание тегов
  • Получение списка тегов
  • Связь many-to-many с задачами

Эндпоинты: - GET /api/tags/ - POST /api/tags/

Архитектура frontend

Структура проекта:

  • src/api — работа с REST API
  • src/router — маршрутизация и защита маршрутов
  • src/views — страницы приложения
  • src/plugins — настройка Vuetify
  • App.vue — корневой компонент

Router guard реализован для защиты маршрутов. Неавторизованный пользователь не может получить доступ к страницам задач и категорий.

Вывод

В ходе выполнения лабораторной работы:

  • реализована клиентская часть приложения на Vue.js
  • настроено взаимодействие frontend и backend через REST API
  • реализована авторизация через Token
  • реализованы CRUD-интерфейсы предметной области
  • настроен CORS
  • подключена UI-библиотека Vuetify

Лабораторная работа №4 выполнена в полном объёме.
